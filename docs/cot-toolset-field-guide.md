# COT Toolset Field Guide

The end-to-end setup walkthrough for the toolset (cotdata, marketdata,
cotmetrics, cot-analyzer, crucible, crucible-stack): clone layout, venv and
env-var setup, populating both stores from CFTC plus a choice of Norgate,
Databento, or Yahoo, the metrics layer, the dashboard, the validation stack,
and commanding a study through Claude Code, with the NPF CS 80/20 book as the
worked example.

It lives on the crucible docs site, which renders it:

**<https://mspinola.github.io/crucible/cot-toolset-field-guide.html>**

The source is `docs/cot-toolset-field-guide.html` in the
[crucible](https://github.com/mspinola/crucible) repo; edit it there. An HTML
copy briefly lived in this directory and was removed in favor of the single
hosted copy, so the two could not drift.
